# CodeAlpha Data Analytics - Task 3: Data Visualization

A simple, beginner-friendly data visualization project for the **CodeAlpha Data Analytics Internship**.

---

## 📌 Project Overview
Using the cleaned 1,000 books dataset, this project creates 4 clear, colorful visualizations using **Matplotlib** and **Seaborn**:

1. **`1_top_categories.png`**: Horizontal Bar Chart showing the top 10 most popular book genres.
2. **`2_price_distribution.png`**: Histogram showing how book prices are distributed, with an average line.
3. **`3_rating_pie_chart.png`**: Pie Chart showing the percentage share of each star rating (1 to 5 stars).
4. **`4_price_by_rating.png`**: Box Plot showing price ranges across different customer star ratings.

---

## 🚀 How to Run in VS Code

### Run the script:
Open your VS Code terminal and run:
```powershell
cd Task_3_Data_Visualization
python main.py
```

### View the charts in Windows:
```powershell
explorer.exe charts
```
Or open the `charts/` folder in VS Code to see all 4 pictures!

### Run the Notebook:
Open `visualization.ipynb` in VS Code and click **Run All**.
